# AI Future Lab --- Master Claude Design & Build Prompt

## Role

You are an expert **creative web designer, UI/UX designer, frontend
engineer, motion designer, and interaction designer**.

Your task is to design and build a visually impressive, futuristic
website called:

# AI FUTURE LAB

The website should feel like a premium interactive AI research
laboratory from the near future.

This is **not** a generic AI landing page.

It should feel immersive, intelligent, cinematic, technical, elegant,
and highly polished while remaining usable and responsive.

------------------------------------------------------------------------

# 1. Core Concept

## Brand

**AI FUTURE LAB**

## Main tagline

> Explore the intelligence shaping tomorrow.

## Supporting message

AI Future Lab is an interactive digital experience that introduces
visitors to artificial intelligence, machine learning, generative AI,
computer vision, neural networks, and the future of intelligent systems.

The website should make visitors feel as if they are entering an
experimental AI research facility.

------------------------------------------------------------------------

# 2. Design Philosophy

Follow these principles:

-   Futuristic but elegant
-   Dark and premium
-   Minimal rather than cluttered
-   Cinematic but fast
-   Interactive without being distracting
-   Technical without becoming difficult to understand
-   Strong typography
-   Large visual hierarchy
-   Generous spacing
-   Smooth motion
-   High-quality micro-interactions
-   Responsive on desktop, tablet, and mobile
-   Accessibility-conscious
-   Performance-conscious

Avoid:

-   Generic corporate AI templates
-   Excessive gradients
-   Excessive glowing text
-   Random floating objects
-   Too many cards
-   Excessive animations
-   Fake-looking stock imagery
-   Cluttered dashboards
-   Poor contrast
-   Animations that make the page difficult to read

The result should look like a professionally designed experimental
technology website.

# 21. Responsive Design

The website must work extremely well on:

-   Desktop
-   Laptop
-   Tablet
-   Mobile

On mobile:

-   Stack sections vertically
-   Reduce particle density
-   Reduce heavy animations
-   Simplify neural network visualization
-   Keep buttons large enough for touch
-   Use a mobile navigation menu
-   Avoid horizontal overflow
-   Ensure all text remains readable

Do not simply shrink the desktop layout.

Design a proper mobile experience.

------------------------------------------------------------------------

# 22. Accessibility

Follow good accessibility practices.

Requirements:

-   Semantic HTML
-   Proper heading hierarchy
-   Keyboard navigation
-   Visible focus states
-   Accessible button labels
-   Sufficient contrast
-   Alt text for meaningful images
-   Respect `prefers-reduced-motion`
-   Do not rely only on animation to communicate information

If reduced motion is enabled, replace complex animations with simpler
fades.

------------------------------------------------------------------------

# 23. Performance

The site should feel smooth.

Requirements:

-   Avoid unnecessarily heavy libraries
-   Avoid excessive DOM elements
-   Optimize animation loops
-   Use `requestAnimationFrame` where appropriate
-   Reduce particle count on mobile
-   Lazy-load noncritical assets
-   Avoid huge images
-   Keep JavaScript organized

Target smooth interaction around 60 FPS on normal modern devices.

# 34. Important Implementation Rule

If a sophisticated visual effect cannot be implemented reliably, create
a simpler polished version rather than a broken effect.

For example:

Bad:

> A complicated 3D neural network that freezes the browser.

Good:

> A lightweight Canvas neural network with smooth animation.

The goal is:

**Premium experience \> unnecessary technical complexity.**
